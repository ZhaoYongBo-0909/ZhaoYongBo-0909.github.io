2背景

要将遥感集成到您的研究和分析中，了解如何解析 Google Earth Engine 上可用的大量栅格数据集非常重要。了解这些数据的分类方式有助于开始这一过程。如果您完全不知道从哪里开始，这里有一个非常有用的资源来细读Google Earth Engine 数据目录中可用的栅格的一般类别。对 Google Earth Engine 中可用的所有栅格执行不同级别的数据清理和图像预处理，但在本模块中，我们将专注于更广泛的探索，为一些示例生态应用程序找到正确的数据集。有关预处理差异和分析的更多信息，请参见模块 5。

2.1数据类别：气候和天气

这些是传达有关温度、降水、蒸发量以及其他大气和气象现象的信息的栅格。这些数据集通常用于帮助了解基于衍生的合适栖息地范围的物种或群落的生态位。重要的是要了解其中一些是通过插值方法创建的，这些方法估计监测站点之间地理空间中的值，而不是许多其他仅提供直接测量值的栅格。



示例集合：CHIRPS

该数据集包含由俄勒冈州立大学 PRISM 小组开发和监测的各种气候层，包括温度和降水。当我们试图在景观水平上理解一个物种或一组物种的潜在生态位时，对气候因素的空间理解是非常宝贵的。



 使用 CHIRPS 数据集的 2018 年 5 月中部非洲的月降雨总量。



2.2数据类别：影像

在该组中，栅格捕捉与被动收集的太阳能相关的景观特征，通常提供有关地面真实世界元素（包括植物和土壤）的增强信息。需要注意的是，影像栅格通常被分成多个子影像（波段），这些子影像对应于特定范围的光波长。许多影像数据集用于创建可通过预建集合访问的光谱索引（更多信息请参见模块 8）。

图片

示例收集：MODIS

MODIS（中分辨率成像光谱仪）程序从两个星载传感器 Aqua 和 Terra 以及两者的组合收集数据。除了表面反射率数据（包括积雪、地表温度、叶面积指数和总初级生产力）外，Google Earth Engine 上还提供了许多衍生的 MODIS 产品。尽管其空间分辨率比其他一些影像数据集更粗糙，但许多 MODIS 产品具有较高的时间分辨率，从而产生密集的时间序列。同一地理区域的图像之间的窗口低至八天。

MODIS 衍生的日本北海道岛叶面积指数预测。

 



2.3数据类别：地球物理

该组中的栅格涵盖范围广泛的地图类型。高程和地形索引图对于定义物种栖息地的环境约束很有用，而土地覆盖图是方便的预打包图层，可用作分类数据或与您自己生成的图像分类进行比较（更多信息请参见模块 7）。



示例集合：NED

国家高程数据集 (NED) 是一个高质量的数字高程模型 (DEM)，它横跨美国大陆以及阿拉斯加和夏威夷的部分地区。该数据集由来自美国各地的不同高程数据编译而成，并经过编辑以确保一致的空间分辨率、高程单位和坐标系。NED 等高程图像可用于创建地形指数、通知洪水模型或对地貌特征进行分类。

3.3探索集合属性

找到并加载我们的集合后，了解对使用遥感数据感兴趣的生态学家可用的图像集合元数据非常重要。元数据对于我们如何确定给定特定研究系统或感兴趣区域的图像或图像集合的适当性很重要。以下主题讨论在 Google Earth Engine 中图像集合的元数据中找到的一些基本信息。



3.3.1空间分辨率

研究生态过程最重要的方面之一是对规模的理解。在遥感的背景下，这被称为分辨率。具体而言，在栅格数据集中，这是对像素大小的基本欧几里德测量，通常报告为栅格中像素一侧的长度。了解空间分辨率与生态应用的物理尺度之间的关系很重要，可以快速帮助您缩小对适当数据集的搜索范围。



要找到我们数据集的空间分辨率，再次输入数据集名称并单击搜索栏中的结果（即“MYD10A1.006 Aqua Snow Cover Daily Global 500m”）。有时，如果栅格中的所有波段的分辨率相同，则此信息（连同比例单位）将显示在标题下。如果数据集中有多个分辨率，通常会有一个表格指示每个波段的空间分辨率。

3.3.2时间分辨率

在遥感领域，有许多数据集代表了在多天、几个月或几年内分析和解释值的机会。时间分辨率是我们描述传感器重访周期的方式。如果卫星具有既定的轨道模式，我们就可以确定预计它经过同一地理位置的日期甚至时间。例如，Landsat 计划在两周内重新访问同一位置，数据采集之间的特定时间分辨率为 16 天。Google Earth Engine 中提供的一些数据集可用于每日测量（即 MODIS），而其他数据集可能是每月测量（即 WorldClim）。

4结论

总之，我们刚刚开始使用 Google 地球引擎探索触手可及的大量数据。我们还介绍了几个重要的元数据片段，它们可以增强您的搜索并帮助确定您的图像集合是否已准备好进行分析。有可能是适合您研究领域的数据集。但是，如果您找不到合适的，请不要担心！只需跳到第4 单元，即可了解如何将您自己的数据引入 Google Earth Engine 生态系统。



4.1完整的图像采集探索脚本

// 加载影像
var dataset = ee.ImageCollection('MODIS/006/MYD10A1');
 
// 设置时间
var dataset = dataset
.filterDate('2018-01-01', '2018-12-31');
 
// 选择波段计算均值
var snowCover = dataset
.select('NDSI_Snow_Cover')
.mean();
 
// 定义视觉参数然后添加地图
var snowCoverVis = {min: 0.0, max: 100.0, palette: ['black', '0dffff', '0524ff', 'ffffff']};
Map.addLayer(snowCover, snowCoverVis, 'Snow Cover');
 
var dataset = dataset
.filterBounds(ee.Geometry.Point(27.5487, 41.2568)); // Use your own coordinates here!
 
// 打印影像数量，
print('Count: ', dataset.size());
 
// 打印过滤后的集合的整个日期范围。
var range = dataset.reduceColumns(ee.Reducer.minMax(), ["system:time_start"])
print('Date range: ', ee.Date(range.get('min')), ee.Date(range.get('max')));
